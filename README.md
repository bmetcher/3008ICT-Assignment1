# 3008ICT-Assignment1
First Order Logic Solver Program, written in C++

### Compile using
```
g++ -std=c++17 main.cpp tokeniser.cpp parser.cpp substitution.cpp solver.cpp -o parser
```
### Running the solver
Just call directly with
```
./parser
```
To try solving all problems currently in the `test.p` file


#### Generate.py
Can edit/use this to generate a set of tautologies with varying complexity to test against
