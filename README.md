# 3806ICT-Assignment1
C++ implementation of Algorithm 2 from Hou's *Fundamentals of Logic and Computation* (2021), with an iterative-deepening on gamma rules improvement.

## Build
```
cd src
g++ -std=c++17 main.cpp tokeniser.cpp parser.cpp substitution.cpp solver.cpp -o parser
```

## Run
The binary reads from `test.p` in the current directory. Copy any dataset file to `test.p` and run:
```
cp ../datasets/pelletier.p test.p
./parser
```

## Datasets
This directory contains the benchmark datasets used in the evaluation.

### pelletier.p
Pelletier problems 1-47, transcribed from Pelletier (1986) into TPTP-style FOF syntax. Used as a handcrafted FOL benchmark.

### generated.p
1900 problems generated by `generate.py`:
- 900 propositional tautologies
- 900 first-order tautologies
- 100 non-tautologies (soundness control)

Run `python3 generate.py generated.p` to regenerate

### TPTP sample
The TPTP problem library itself is not redistributed here due to it's own distribution terms. Download it from https://tptp.org and run `tptp_runner.py` against the extracted Problems directory:

```
python3 tptp_runner.py /path/to/TPTP/Problems ./parser tptp_results.txt 100
```
The file `tptp_results.txt` contains our actual results from this test
